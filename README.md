# Finance Management Web

A modern web application for personal finance management built with React, TypeScript, and Shadcn UI.

## Tech Stack

- **React 18** - UI Library
- **TypeScript** - Type Safety
- **Vite** - Build Tool & Dev Server
- **Tailwind CSS** - Styling
- **Shadcn UI** - UI Components
- **Lucide React** - Icons

## Project Structure

```
finance-management-web/
├── public/              # Static assets
├── src/
│   ├── assets/          # Images and static files
│   ├── components/      # Reusable UI components
│   ├── constants/       # App-wide constants
│   ├── contexts/        # React contexts
│   ├── hooks/           # Custom React hooks
│   ├── lib/             # Utility functions
│   ├── pages/           # Page-level components
│   ├── services/        # API services
│   ├── types/           # TypeScript type definitions
│   ├── utils/           # Helper functions
│   ├── App.tsx          # Root component
│   ├── main.tsx         # Entry point
│   └── style.css        # Global styles with Tailwind
├── .env                 # Environment variables
├── .env.example         # Environment variables template
├── index.html           # HTML template
├── package.json         # Dependencies and scripts
├── tailwind.config.js   # Tailwind configuration
├── tsconfig.json        # TypeScript configuration
└── vite.config.ts       # Vite configuration
```

## Getting Started

### Installation

```bash
npm install
```

### Development

```bash
npm run dev
```

The application will be available at `http://localhost:5173`

### Build for Production

```bash
npm run build
```

### Preview Production Build

```bash
npm run preview
```

## Configuration

### Environment Variables

Create a `.env` file in the root directory:

```env
VITE_API_URL=http://localhost:3000
```

### Tailwind CSS

The Tailwind configuration is in `tailwind.config.js`. To customize the theme:

- Colors are defined using CSS variables (HSL values)
- Components use the utility classes generated by Tailwind
- Dark mode is supported via the `.dark` class

### TypeScript

TypeScript configuration is in `tsconfig.json`. Type definitions are in `src/types/`.

## Utilities

### `cn()` function

A utility for merging Tailwind classes with proper precedence:

```typescript
import { cn } from '@/lib/utils'

cn('px-4 py-2', 'text-sm', active && 'bg-primary')
```

### API Service

A wrapper around fetch for API calls:

```typescript
import { api } from '@/services/api'

// GET request
const data = await api.get('/api/transactions')

// POST request
const result = await api.post('/api/transactions', transactionData)
```

## Component Structure

- **Components**: Reusable UI building blocks
- **Pages**: Route-level components that compose components
- **Layouts**: Page layout structures (header, sidebar, etc.)

## Best Practices

1. Use TypeScript types for all components and functions
2. Keep components small and focused
3. Use the `cn` utility for conditional styling
4. Follow the established folder structure
5. Use environment variables for configuration
6. Keep API calls in service files
7. Use React hooks for state and side effects
